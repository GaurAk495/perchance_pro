Perchance shows a one-time notice to first-time visitors. It only takes a few seconds:

Per-prompt negative prompts

Give a single prompt its own negative prompt instead of the global one. Per-prompt wins; otherwise the global negative is used.

!text right after a prompt = that prompt's negative.

prompt | negative or prompt ! negative on the same line = that prompt's negative (a | or ! with spaces around it).

<negative> on its own line = prompt is everything above it (may be multiple lines), negative is everything below it until a blank line.

CSV file with 2 columns (prompt, negative) — import as a .csv file.
